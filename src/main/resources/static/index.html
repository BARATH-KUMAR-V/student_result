Jenkins CI/CD Pipeline & Database Architecture

Automated pipeline setup for compiling, testing, packaging, and archiving the Spring Boot Student Result Portal.

Jenkins Declarative Pipeline Stages

Stage 1

Checkout

Pull latest source code from SCM / Git repository.

checkout scm
→
Stage 2

Build

Compile Java source code & validate project dependencies.

mvn clean compile
→
Stage 3

Test

Execute JUnit tests & publish test results report.

mvn test
→
Stage 4

Package

Assemble executable Spring Boot runnable JAR file.

mvn package -DskipTests
→
Stage 5

Archive

Save build artifact JAR for deployment & distribution.

archiveArtifacts 'target/*.jar'
H2 Database

In-Memory Development Database

Currently active out-of-the-box. No external installation required.

  • Console URL: http://localhost:8080/h2-console
  • JDBC URL: jdbc:h2:mem:studentdb
  • Username: sa
  • Password: (leave blank)
MySQL Database

Production Ready Integration

To switch from H2 to MySQL, update application.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/studentdb
spring.datasource.username=root
spring.datasource.password=your_password
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=update
